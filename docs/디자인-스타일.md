# 디자인 스타일 (2026-10-26)

근거는 마디아 「AI디자이너」 1~3부 첨삭 하나뿐이다(위키 `projects/gamedev/개인프로젝트/레퍼런스/마디아-AI디자인-피드백-정리.md`).
위키의 「UI 목업 검수 체크리스트」는 쓰지 않는다. 그 표는 Wild Arcana 게임 UI 문법(명조 참고, 흰 알약 버튼·무채 틀·금색 규칙)을 정본으로 둔 것이라,
이 웹 퀴즈에 쓰면 게임 메뉴 톤(라운드 999 알약, 48px 방 코드, 넓은 카드 여백)이 된다. 첫 판(`6ae2e46`~`3c48e9a`)이 그랬다.

## 규칙

| # | 규칙 | 값 | 마디아 근거 |
|---|---|---|---|
| 1 | 바탕은 무채, 경계는 회색 1px 선 | 바탕 `#0f1011`, 카드 `#17181a`, 선 `#2a2b2f` | 1부 수정 후 「무채 바탕+회색 선」 |
| 2 | 색은 정보에만 | 초록 정답, 빨강 오답·시간 부족, 호박색 나·핀·묻는 나라 이름. 탭·버튼·카드·점수 숫자에는 색 없음 | 1부 「색은 이미 정보가 가져온다」 |
| 3 | 그라디언트·발광 없음 | 쓰는 그림자는 출제 방식 손잡이의 1px 짝(위 밝음·아래 어두움) 하나 | 1부 이펙트 절제, 3부 토글(바닥은 파이고 손잡이만 튀어나옴) |
| 4 | 강조는 크기 → 굵기 → 색 | 결과 점수 40, 질문 20, 나머지 16 이하. 굵기 600은 이름·제목·주 버튼만 | 1부 「크기로 강조」, 3부 「가벼운 것은 가볍게」 |
| 5 | 주 행동 버튼은 화면에 하나 | 밝은 면 버튼(`.btn.primary`). 나머지는 테두리만 | 3부 「강조는 하나만」 |
| 6 | 촘촘하게 | 여백 12~16, 라운드 8(안쪽 6), 버튼 36(폰 40, 큰 버튼 40/44) | 1부 밀도·버튼 크기 |
| 7 | 글자 크기 | 12/13/14/16/20/28/40만 | 1부 글자 계층 |
| 8 | 같은 부품은 같은 배치, 상태가 바뀌어도 높이·여백이 같다 | 사람 목록 행 36, 문제별 결과 행 같은 격자 | 2부 형식 불일치, 3부 호버 여백 |
| 9 | 떠 있는 것은 딤 없이 1px 선 | 알림(토스트) 선 `#444` | 2부 영역 구분, 3부 딤 금지 |
| 10 | 장식·반복 없음 | 점선 테두리 대기 표시 → 회색 글자 한 줄 | 1부 반복·장식 제거 |

참고 구도: 처음·결과는 폭 480 한 줄 카드(웹 단어·국기 퀴즈의 흔한 구도), 대기실은 방 코드 → 설정 → 참가자 → 시작 순서의 웹 멀티게임 대기실.

## 점검

캡처(`tools/capture`)를 찍은 뒤 위 표의 값으로 센다. 「깔끔해 보인다」는 판정이 아니다.

- `style.css`에서 `gradient` 0개, `box-shadow` 줄은 출제 방식 손잡이 하나, `999px` 0개 (`grep -n "gradient\|box-shadow\|999px" style.css`)
- `font-size` 값이 7번 목록 밖이면 실패
- 한 화면에 `.btn.primary`가 둘 이상 보이면 실패
