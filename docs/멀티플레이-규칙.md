# 멀티플레이 규칙 (초안)

혼자 하기 규칙(README §1)은 그대로 두고, 여럿이 한 방에서 겨룰 때 달라지는 것만 적습니다.
2026-10-26 사용자와 정한 결정은 **[결정]**, 아직 확인하지 않은 기본값은 **[기본값]**으로 표시합니다.

## 1. 정한 것

* **[결정] 동시 출제.** 방의 모두가 같은 국기 10개를 같은 순서·같은 타이머로 풉니다. 문제는 서버가 한 번 뽑아 모두에게 보냅니다.
* **[결정] 이름은 각자 입력창.** 남의 답은 보이지 않고, 누가 맞혔는지만 점수판에 「정답!」으로 뜹니다. 늦게 맞혀도 혼자 하기와 같은 시간 곡선으로 점수를 받습니다(바로 100 → 시간 끝 20).
* **[결정] 넘어가기 = 전원 답 또는 시간 끝.** 단계(이름 15초, 지도 25초)마다 접속 중인 사람이 모두 답했거나 제한 시간이 끝나면 다음으로 넘어갑니다.
* **[결정] 문제 결과 화면에 모두가 누른 위치.** 지도 단계가 끝나면 정답 나라를 칠하고, 참가자마다 누른 자리를 닉네임 핀으로 찍습니다. 지도 단계 중에는 남의 핀을 보여 주지 않습니다.

### 1.1 지도 누르기 (모바일 대책)

멀티에서는 점수가 걸려 있습니다. 혼자 하기처럼 손가락을 떼는 순간 바로 제출하면, 확대하다 잘못 눌리거나 손가락에 가려 다른 나라를 누른 실수가 그대로 점수가 됩니다.

* **[결정] 핀 놓고 확정.** 누르면 핀만 꽂히고, 다시 누르면 핀이 옮겨집니다. 크게 뜨는 「확정」 버튼을 눌러야 제출됩니다. 끌기·두 손가락 확대는 지금처럼 핀을 건드리지 않습니다(8px 넘게 움직이면 끌기).
  * 점수 시각은 **마지막으로 핀을 놓은 때**입니다. 확정 버튼을 늦게 눌러도 손해가 없어서 확정 전에 한 번 더 확인할 수 있습니다.
  * 시간이 끝나면 놓인 핀이 자동 제출되고, 핀이 없으면 무응답입니다.
  * 「전원 답」 판정은 확정 기준입니다.
* **[결정] 지도 전체 화면.** 지도 단계에서는 국기·점수판을 위쪽 한 줄(국기 작게, 나라 이름, 남은 시간)로 접고 지도가 나머지 화면을 채웁니다. 가로로 돌리면 가로로 채웁니다.
* **[결정] 지도 단계 25초.** 혼자 하기의 20초보다 5초 늘립니다. 모두 똑같이 적용하고, 점수 곡선(바로 100 → 시간 끝 20)도 25초 기준으로 계산합니다. 혼자 하기에도 맞출지는 나중에 정합니다.
* 이미 있는 완화책은 그대로 둡니다: 경계 바깥 24px·400km 안은 정답, 틀려도 2,000km 안이면 최대 40점.

## 2. 한 문제의 흐름

1. 이름 단계 (15초): 국기를 보고 각자 이름을 씁니다.
2. 이름 결과 (약 2초): 정답 나라 이름과 맞힌 사람을 보여 줍니다. **[기본값]**
3. 지도 단계 (25초): 지도가 전체 화면으로 커지고, 각자 핀을 놓은 뒤 「확정」을 누릅니다(§1.1).
4. 지도 결과 (약 5초): 정답 나라, 모두의 핀과 거리(km), 이번 문제 점수. **[기본값]**
5. 다음 문제. 10문제가 끝나면 최종 순위.

## 3. 아직 정하지 않은 것 (기본값으로 시작)

| 항목 | 기본값 | 이유 |
|---|---|---|
| 방 인원 | 최대 12명 | 여행 인원 8명에 여유 |
| 판 시작 | 방장이 「시작」을 누름 | 다 모일 때까지 기다림 |
| 중간 입장 | 다음 판부터 참가, 그 전엔 구경 | 점수가 0부터라 불공평 |
| 접속 끊김 | 「전원 답」 판정에서 빼고, 다시 들어오면 이어서 | 한 사람 때문에 매번 시간 끝까지 기다리지 않음 |
| 정답 판정 | 서버가 함 (클라이언트는 입력·누른 좌표만 보냄) | 정답이 미리 새지 않고 점수를 조작할 수 없음 |
| 시간 기준 | 서버가 단계 시작 시각을 정하고 남은 시간을 내려 줌 | 폰마다 시계가 달라도 같은 타이머 |
| 최종 순위 | 총점 순, 같으면 이름+위치 맞힌 수 | |

## 4. 서버 (예정)

Cloudflare Workers + Durable Objects로 방 하나를 객체 하나로 둡니다. 화면은 지금처럼 GitHub Pages에 둡니다.
`js/engine.js`가 node와 브라우저 둘 다에서 도므로, 서버도 같은 채점 코드를 씁니다.
